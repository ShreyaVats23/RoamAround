# 🧭 Overview
RoamAround is a web-based travel companion designed to help people visiting Delhi for the first time. Whether you're into history, food, nature, or local markets, RoamAround helps you explore and navigate to places that match your interests — all from one simple interface.

# ✨ Features (Planned and Implemented)
-> Interactive UI showcasing different locations<br/>
-> Basic information about top tourist spots<br/>
-> Navigation support using Google Maps or similar service<br/>
-> User preference-based recommendations<br/>
-> Itinerary planning<br/>

# 📍 Use Case
Imagine you're new to Delhi and want to make the most of your visit. RoamAround:<br/>
-> Shows you famous and lesser-known places<br/>
-> Lets you select your interests<br/>
-> Will (in future updates) suggest an optimized route to explore them<br/>
